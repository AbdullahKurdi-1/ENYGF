## Key results (independent copy; the student's rerun gives the final ones)

| | CFD | DNS |
|---|---|---|
| gap wall shear tau/tau_m | 0.47 | 0.81 |
| k+ at gap centre | 0.26 | 2.50 |
| Theta/Theta_b gap centre, Pr 0.025 / 1 | 0.18 / 0.52 | 0.18 / 0.88 |
| Nu iso-T Pr 1 (medium / extrapolated) | 33.4 / 35.1 | 38.7 |
| Nu iso-flux Pr 1 | 25.4 | 40.2 |

PINN vs CFD errors are 10-100x smaller than CFD vs DNS: the DNS disagreement
is the turbulence model's, not the machine learning's.

## Decisions

- Production CFD stays on the medium mesh (ML conclusions do not depend on
  mesh error); CFD-vs-DNS statements quote the mesh uncertainty (GCI) and the
  extrapolated values.
- The nu_t fix is the new default; everything is retrained with it.
- Sensitivity tests (Kays Pr_t, pure conduction) are reported as tests of
  explanations, not used for results.

## Limitations found

- Low observed order of grid convergence for high-Pr Nusselt numbers
  (p ~ 0.5): the thermal wall layer needs finer near-wall cells.
- Lines-only PINN slightly worse with the nu_t fix (single seed; within the
  expected spread) - to be confirmed by the seed runs.
- A literature point (Baglietto & Ninokata 2005) is cited from memory and
  must be checked before it goes into the paper.
